# RevCast AI

Probabilistic revenue forecasting and budget optimization platform for paid media. RevCast AI uses **Monte Carlo simulation** to forecast campaign performance, generate confidence intervals, and provide AI-powered insights to support marketing budget decisions.

🌐 **Live Demo:** https://revcast-frontend.onrender.com

## Tech Stack

* FastAPI
* Next.js 14
* Python
* TypeScript
* Monte Carlo Simulation
* REST API

## Repository

```bash
git clone https://github.com/keerthishree20/RevCast-AI.git
cd RevCast-AI
```

## Prerequisites

* Python 3.10+
* Node.js 18+
* Git

## Backend Setup

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

Backend runs at:

```
http://localhost:8000
```

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend runs at:

```
http://localhost:3000
```
